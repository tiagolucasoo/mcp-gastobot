
==> PARA EXECUTAR O SERVIDOR MCP JAVA DIRETAMENTE: 
  "mcpServers": {
    "NOME_DO_SERVIDOR": {
      "command": "java",
      "args": ["-jar", "DRIVE:\\caminho\\absoluto\\para\\servidor.jar"],
      "env": { "MCP_FILES_ROOT": "DIRETÓRIO_VÁLIDO" }
    }
  }

onde:
NOME_DO_SERVIDOR: escolha um nome para o servidor, MCP Java Server, por exemplo;

DRIVE:\\caminho\\absoluto\\para\\servidor.jar:
DRIVE (Windows): C: ou D:
\\caminho\\absoluto\\para\\servidor.jar: caminho (nome(s) de diretório(s)) até
                                         o nome do arquivo que representa o
                                         servidor MCP Java

DIRETÓRIO_VÁLIDO: o nome de um diretório válido (deve existir no sistema de
                  arquivos)

==> PARA EXECUTAR O SERVIDOR MCP JAVA A PARTIR DO DOCKER:
      "mcp-server-01-docker": {
         "command": "docker",
         "args": [
            "compose",
            "-f",
            "DRIVE:\\caminho\\absoluto\\do\\projeto\\compose.yaml",
            "run",
            "--rm",
            "-T",
            "--no-deps",
            "mcp-server"
         ]
      }

onde:
DRIVE:\\caminho\\absoluto\\do\\projeto\\compose.yaml: caminho para o arquivo
                                                      compose na raiz do projeto 
(D:\desenvolvimento\java\eclipse\eclipse-workspace\mcp-server01\compose.yaml)

-f: informa qual arquivo compose utilizar
run: executa um serviço em um novo container
--rm: remove o container ao terminar
-T: não aloca um terminal pseudo-TTY
--no-deps: não inicia outros serviços dependentes
